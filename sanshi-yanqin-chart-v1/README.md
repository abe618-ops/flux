# 三式 · 演禽排盘 V1

Android 离线排盘工具。第一版只做排盘与资料校验，不包含足球预测。

## V1 已实现

- **奇门遁甲**
  - 时家奇门：拆补法、转盘九宫
  - 刻家 A：10 分钟五马遁口径（用于对照堅奇門公开实现）
  - 刻家 B：一时辰十刻、每刻 12 分钟的十分局对照口径
  - 日家、月家、年家基础盘
  - 九宫显示：地盘干、天盘干、九星、八门、八神、值符、值使
- **太乙神数**
  - 年计、月计、日计、时计
  - 七十二局基础层
  - 太乙、文昌、始击、计神
  - 主算、客算、定算与主客大将/参将
- **大六壬**
  - 月将
  - 天地盘
  - 四课
  - 唯一贼克/元首等可直接确定时生成基础三传
  - 复杂九宗门课式暂不伪造，留到 V1.1
- **演禽**
  - 二十八宿值日宿
  - 二十八宿禽星环
  - 七曜基础显示
  - 翻禽倒将、演禽通纂/禄命、万化仙禽后续分别实现
- **资料页**
  - 区分“三式”与“演禽”
  - 记录刻家不同口径
  - 分家/秒家暂列待考，不冒充古法

## 研究口径

V1 的目标是先建立“可复现、可切换、可继续校准”的底盘。对存在明显流派差异的算法，不用一个结果覆盖全部流派。

重点基准资料：

- 《遁甲演义》
- 《奇门旨归》
- 《太乙金镜式经》
- 《禽星易见》
- 《演禽通纂》
- kentang2017/kinqimen
- kentang2017/kintaiyi
- kentang2017/kinliuren
- kentang2017/yanqin_studies
- kentang2017/kinastro（万化仙禽）
- 6tail/lunar-java（历法、干支、节气、二十八宿基础）

## V1.1 待补

## V2 规划：足球赛前预测

V2 在 V1 排盘引擎稳定后新增，不改动 V1 的原始排盘结果：

- 比赛信息：主队、客队、开赛时间、时区
- 四术独立输出：奇门 / 太乙 / 六壬 / 演禽
- 合参层：胜平负、总进球、大小 2.5、单双、半全场、比分候选
- 原始盘与足球映射分层保存，可复盘、可盲测
- 每场保留算法版本、口径和时间输入，避免事后改盘
- 后续再接统计足球模型；传统术数与统计模型分别计权，不互相篡改原始结果

## 构建

Android Gradle Plugin 8.7.3 / Java 17 / compileSdk 36 / minSdk 26。

```bash
gradle :app:assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`
