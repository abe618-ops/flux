# 竞彩北单模拟 · 多源修复版 v2.2.1

针对 v2.2 “北单列表有比赛但 0 场有赔率”的专项修复。

## 修复点
- 不再依赖球探页面中的 `beiDanSchedule` 数组来取得 Titan ID。
- 北单列表仍由现有公开北单赛程页提供，随后读取球探/新球体育整日赛程，按“日期 + 主客队名”匹配 Titan 赛事 ID。
- 中文队名允许“(中)”、排名、简称等规范化差异；编号回退匹配的时间窗口放宽到 180 分钟。
- 先完成北单赛程，再完成球探映射，避免两个异步来源先后顺序造成 0 个 Titan ID。
- 赛果同步同样改为整日球探完场比分，不再依赖北单赛程数组。
- 自动公司顺序保持：12BET → 10BET → Bet365 → Crown → 澳门。
- 顶部状态增加“已映射 X 场”，可以直接判断到底是赛事 ID 没匹配，还是公司本身没有该场赔率。
- 北单混合页先只展示已自动接通的胜平负公司盘，避免把尚未自动接通的总进球赔率显示成一排“暂无可靠赔率”。

## 并存
applicationId 为 `com.flux.virtualbet.multisource.fix1`，与旧版和 v2.2 都可同时安装，用于直接对照测试。

仅用于本地赔率指数学习与虚拟模拟，不接入支付、充值、出票或真实投注账户。
