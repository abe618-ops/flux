# 六爻·穿禽足球合参 V2.0（2026-10）

这是在原 **术数足球合参 v0.1** 原生 Android 项目上扩展的独立安装版。保留原先六门：梅花、太玄、轨策、大定、演禽、铁板；新增 **完整六爻纳甲** 与 **禽星穿六爻实验层**，共八路独立结果页，外加一个合参首页。

## 使用方式

启动直接显示综合预测，主队/客队可以留空（中性主客）。默认按中国北京时间计算；“比赛时刻盘”固定日期和时间可复现，“随机实验盘”使用系统安全随机种子。点击「随机下一场 · 一键预测」便可直接得到新盘，点击各术标签查看其结果，点「展开／收起各术排盘与取数依据」查看六爻或演禽的逐项明细。

输出：胜平负、半场比分、半全场、总进球主选与三档候选、比分主选/前三、大小 2.5／上下、进球单双、净胜球、λ 主客。计算框架先由各术数得到主客相对态势及节奏，再通过同一泊松比分矩阵生成各玩法，不把各玩法各自任意摇出不同结果。类别最高权重胜平负与最高单个比分可能不同，因此主选比分选择在主胜平客主方向内概率最高的一组，全部无条件前三比分另作比较。

### 八路计算

1. **六爻纳甲**：调用与之前《六爻三位数研究》同一版排盘核心。三枚钱六次生成 6/7/8/9 爻值，纳甲、八宫、世应、六亲、六神、月日旺衰、旬空、本变卦、动爻，保留独立明细。以世应旺衰与动静做主客差，子孙/官鬼/妻财与动爻数做进球节奏；引用后天卦数、河图五行、地支太玄等做次级取数。这些从占卜数转换为足球 λ、进球数的步骤均是现代实验映射。
2. **禽星穿六爻**：与第 1 路使用同一六爻盘，以固定的时禽起点，将禽星顺次覆于每一爻，再检查禽五行与爻支五行的生克、动静、世应。本版固定「每爻顺推四宿」便于复现，但**没有证据证明这就是传统六爻穿禽的完整法式**；不应与古籍原文混同。与演禽同源，合参给较低权重，避免多次重复计票。
3. **梅花**：本互变中的主卦数与体用关系节奏，保留原引擎既有固定取数定义。
4. **太玄**：81首/九赞与干支太玄辅助数，区分古法与足球近似。
5. **轨策**：演周易/策轨，元会运世对侧映射属实验约定。
6. **大定**：天地人物数，动数及主客气数。
7. **演禽**：日禽、时禽、翻禽、倒将与我彼五行；系原项目的简化数理实现，尚不是完整《禽星易见》七元时禽及倒将的严格复原。
8. **铁板**：时刻滚序与数字核，未内置命理条文。

八路合参按固定权重计算：六爻 1.5，穿禽 0.4，其余每路 0.85。权重是尚未经回测验证的实验参数，不是由真实比赛效果学习得出。

### 六爻穿禽资料核查

- 明代池本理《禽星易见》收入《四库全书》，可核验“七元时禽”“翻禽倒将”“到将为彼、翻禽为我”等内容：
  https://zh.wikisource.org/zh-hans/%E7%A6%BD%E6%98%9F%E6%98%93%E8%A6%8B_(%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC)
- 《禽星易见》第三卷“七元时禽总括”分七元起宿；这说明日禽/时禽有完整算法，不能简单声称由任意年月日除28就完全还原：
  https://libokang.com/guji/zhanbu/%E7%A6%BD%E6%98%9F%E6%98%93%E8%A7%8B/3/
- 六爻排盘系统有同时显示十二长生、二十八宿（禽星）的现代做法，但不等于二者合叠的预测公式已获得古籍逐条校正：
  https://hexagram.qiankunyi.com.cn/

### 冻结、复盘和统计

“赛前冻结”保存 Seed、八路模型结果、哈希摘要到 Android 私有本地存储，后续“赛后复盘”只读取冻结内容，不使用新盘。输入全场比分（如 2:1），可选填半场比分（如 1:0），输出各门胜平负、大小 2.5、进球单双、首选比分与前 3 比分、半全场是否一致（未填半场不计）。累计统计对同一个冻结快照的反复复盘只计一次。本地 SHA-256 用于检测快照相等，不代表第三方公证时间戳。会保留历史冻结索引，当前实现只提供最近一个快照复盘。

### 编译

项目：`shushu-football/`，Gradle Android 插件 8.7.3、Java 17、compileSdk 35、minSdk 26（Android 8+），依赖 `cn.6tail:lunar:1.7.7`。编译工作流：`.github/workflows/build-shushu-football.yml`；正式交付以其最新编译成功且 Android 签名与 zipalign 检查通过的 APK 为准。新版 Android 应用 ID：`com.abe.shushufootball.hexqin.v2`，和旧版并存。

> **研究边界**：传统象数和禽星占法没有可靠科学证据能预测真实足球比分；本软件不联网拉取比赛或盘口、不收集投注信息、不保证胜率。方向、比分、总球必须通过真实比赛的事前冻结和长期统计验证，而不是在已知结果后调整权重。

## 原版说明（保留）
# 术数足球合参 ShuShu Football v0.1

Android 离线研究版。六门独立模型：梅花、太玄81首/太玄数、演周易/策轨、大定、演禽、铁板数字核。

## 已实现
- 比赛时刻盘：同一球队 + 同一时间可复现。
- 随机实验盘：SecureRandom 生成 64-bit Seed，并显示 Seed 便于复盘。
- 六门分别输出：胜平负、半全场、总进球、比分 Top3、大小2.5、单双、净胜球。
- 合参：首版等权平均六门 λ 主/λ 客。
- 统一比分层：所有玩法来自同一 0:0~6:6 泊松矩阵，避免逻辑互相冲突。
- 演禽保留日禽/时禽/翻禽/倒将与我彼五行关系；铁板不调用人命条文库。

## 模型分层
传统排盘/取数规则与“足球映射层”分开。元会/运世→主客、体用→主客、我彼→主客等属于竞技适配规则；后续可通过盲测数据库逐项修订。
