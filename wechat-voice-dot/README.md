# 微信语音点（WeChat Voice Dot）V1

这是一个验证“隐藏普通键盘，只保留固定语音按钮，并借用微信输入法自身语音识别”的 Android 原型。

## 交互

- 默认：辅助服务将软键盘保持隐藏，只显示一个固定麦克风按钮。
- 按住麦克风：临时恢复微信输入法，定位其空格键并注入持续按压手势；松开按钮后结束手势，等待微信输入法识别并上屏，再折叠键盘。
- 向屏幕中央快速滑动麦克风：临时显示完整微信输入法键盘。
- 位置调整：在主界面开启“调整语音点位置”，拖动后会自动吸附左右边缘及 7 个固定槽位；关闭后位置锁定，不会随普通触摸漂移。

## 前提

1. 手机已安装微信输入法（包名 `com.tencent.wetype`）。
2. 微信输入法设为当前默认输入法。
3. 微信输入法中开启“长按空格语音转文字”（若当前版本仍提供此开关）。
4. 系统设置中开启“微信语音点辅助服务”。

## 说明

V1 不录音、不接入任何自有 ASR，也不需要 API Key。语音识别由微信输入法完成。

这是实机验证原型。不同微信输入法版本/键盘布局可能不暴露“空格”辅助节点，因此实现包含两级定位：优先查找空格节点；找不到时按输入法窗口底部中心位置回退。后续可根据实机结果加入精确校准。
