# 合参实验室 v1.3 · 稳定安装 / 单双合参

这是针对 v1.2“安装失败”重做的完整 Android 工程，不再修改旧 APK 二进制包名。应用使用独立包名 `com.abe618.footballfusion.v13`，可与旧版并存；CI 使用 Android Gradle Plugin 正常构建，并用 `apksigner` 验证 APK Signature Scheme v2+。

## 核心变化

- 方法仍按历史表现排序：胜负 58% + 大小 42%，本机复盘逐步接管弱先验。
- 排名前两项若胜负方向不同，自动重新抽取，直到前两项同为主胜或同为客胜；界面显示自动抽取次数。
- 顶部压缩，结果后直接显示 15 种方法纵向排行，减少向下翻页。
- 胜负、大小继续使用单法历史权重 + 达标 2–5 家共振；共振只作有限修正，避免小样本 2/2、3/3 被误当作稳定规律。
- 新增逐术数单双：15 种方法分别取数并给出“单/双”，再按各自后续复盘成绩进行总体单双合参。

## 单双取数

当前采用可冻结、可复盘的实验映射：大衍/策数使用 49 域；太玄使用 81 态域；五行数使用河图 1–10 数值；梅花采用 8/8/6；六爻采用 6/7/8/9；奇门采用九宫 1–9；小六壬采用六位循环；灵棋采用十二位循环等。软件明确把这些标为“实验映射”，不宣称是某一古籍的唯一传统定法。
