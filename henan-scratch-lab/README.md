# 河南刮刮乐 · 四术合参研究 APK（beta1）

2026-10-08 接续河南即开彩票资料整理项目，提供可构建的离线安卓工程。

## 当前交付范围
- 北京时间正时、手动活时、系统安全随机时刻。随机数优先 Web Crypto，设备原生 SecureRandom 兜底；没有安全源则阻止生成。
- 六爻：三钱法六次独立随机取 6/7/8/9、上下八卦、动爻记录。
- 六壬/转盘奇门/梅花：明确标记**实验性数值映射，尚非完整古法排盘**；分开显示再四家方向合参。
- 8 方位、网点序号、用户输入的店铺编号、模拟票册位置与颜色；本机历史封存、盈亏统计、JSON 复制。
- 票种仅列可核验的部分体彩代表票：吉（20元）、中国风（30元）、华夏寻宝·唐（50元）。「顺」及福彩仍待核实；不宣称河南全量在售目录。
- 完全离线：不申请网络、位置或存储权限，不接入彩票购买/兑奖。

## 重要准确性边界
目前不能证明任何术数、门店方位、彩票序列、颜色可提高中奖概率；这些数字只用于研究、盲测与独立复盘，不能理解为中奖预言。不能把实验性数值映射伪称大六壬四课三传、奇门完整转盘或正式农历梅花排盘。未来接入可核验规则时必须升级模型版本，同时保留历史冻结预测。

## 构建
安装 Android SDK Platform 35 / Build tools 35、JDK 17、Gradle 8.9：
```bash
gradle -p henan-scratch-lab assembleDebug
```
产物：`henan-scratch-lab/app/build/outputs/apk/debug/app-debug.apk`；debug 签名用于内部安装，不是发布级私钥。GitHub Actions [Henan Scratch Lab Android] 自动构建并上传 APK Artifact。

## 验收要点
1. 安装并启动，离线进入页面（Android 7.0+）。
2. 正时显示北京日期，手动活时可修改；安全随机模式每次生成时刻、随机种子、六爻序列。
3. 切换体彩/福彩。体彩代表票显示价格，福彩明确提示未核实。
4. 编辑店铺列表，输出只从输入列表选择；店铺号及票张位置落在限制内。
5. 保存记录、杀后台重开，历史仍在；填写实际花费和奖金后正确显示净额。
6. 系统返回键、屏幕旋转、打开多次不闪退。
