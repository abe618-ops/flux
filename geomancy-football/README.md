# 地占足球实验室 Android v0.1

一个本地运行的地占术足球盲测/复盘工具。首版按当前冻结模型完成三类盘面与完整赛果输出。

## 已实现

- 盾形阵列、传统十二宫、克劳利三种排盘视图。
- 四母独立起局；四女、四侄、左右见证、法官、调停者严格按奇偶派生，不把16个图形分别乱抽。
- 随机 Seed 与固定文字/数字 Seed 两种起局方式，同一 Seed 可完全复现。
- 结果置顶：胜平负、半全场、总进球、大小2.5、单双、双方进球、首选比分与三个比分候选。
- 固定足球轴：1/7宫主客、5/11宫攻门、10/4宫结局、左右见证过程、法官终局、调停者总趋势。
- 四轴投票公开显示，避免黑箱式“事后解释”。
- 原生 Java + Android SDK，无第三方运行时依赖，Android 8+（minSdk 26），targetSdk 36。

算法细节见 `MODEL.md`。

## 构建

```bash
gradle :app:assembleDebug
```

GitHub Actions 会自动构建，并把可安装 APK 写入仓库：

`dist/GeomancyFootball-v0.1-debug.apk`

同时保留 Actions artifact 方便核验。

## 定位

这是用于记录、盲测和回测的实验软件。地占术与足球结果之间没有已建立的科学预测关系，因此“合参倾向度”只表示内部信号一致程度，不等于真实获胜概率。
