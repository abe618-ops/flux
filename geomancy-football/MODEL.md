# 地占足球实验模型 v0.1（冻结规则）

## 1. 起局与推导

- 仅四母独立随机生成，每一行只取奇/偶两态：单点=1，双点=2。
- 四女由四母逐行转置得到。
- 四侄、左右见证、法官、调停者均使用传统奇偶合并：同奇偶得双点，一奇一偶得单点。实现上以 `1=单点、0=双点` 编码，所以合并等于 XOR。
- 同一个 Seed 必须生成完全相同的全盘与预测，便于盲测和复盘。

## 2. 三种盘面

1. **盾形阵列（Shield Chart）**：四母 → 四女 → 四侄 → 左右见证 → 法官 → 调停者。
2. **传统十二宫**：前12个派生图形按十二宫位显示，强调一七、五十一、十四六条足球轴线。
3. **克劳利布局**：使用 Crowley 风格的交叉菱形排版，并用另一宫位视觉顺序显示同一组数据；法官置中作为终局参考。

三种盘面是同一局数据的不同展示，不允许切换布局时重新随机，以免发生“看盘后换局”。

## 3. 足球映射

这是实验映射，不宣称是古籍中的足球定法。

- 主客轴：1宫 vs 7宫。
- 攻门轴：5宫 vs 11宫。
- 结局轴：10宫 vs 4宫。
- 过程：右见证 vs 左见证。
- 终局：法官。
- 总趋势：调停者。

主队指数与客队指数分别由上述四条轴加权，再由法官/调停者与1、7宫的同异关系作轻度修正。四条轴分别投票，最终显示在结果卡片下方。

## 4. 总进球、单双与比分

遵循此前复盘冻结原则：**象定方向、气定大小、数定进球区间、阴阳定单双、过程象定半场**。

- 进球量首先由5/11宫、左右见证、法官、调停者、1/7与10/4轴的单点活跃度合成原始总球值。
- 单双由法官、调停者、5宫、11宫的点数奇偶共同给出；如果和原始总球奇偶冲突，只做相邻一球修正。
- 平局必须是偶数总球；主胜/客胜不能出现0球。
- 比分不得从单一图形直接硬猜：先冻结胜平负，再冻结总球与单双，然后按主客指数差分配主客进球。
- 输出3个比分候选，但首选比分固定放在最前。

## 5. 固定输出顺序

**胜平负 → 半场/半全场 → 总进球 → 大小2.5 → 单双 → 双方进球 → 比分候选**。

“合参倾向度”只是模型内部的一致性刻度，不是真实世界概率。

## 6. 复盘纪律

- 每场独立起局并保存 Seed。
- 赛前结论冻结；不得根据赛果回改当场规则。
- 胜平负、大小球、单双、半全场、比分分别统计命中率。
- 大幅调权至少等待30场；模板稳定性至少100场后评估。
