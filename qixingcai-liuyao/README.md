# 体彩七星彩·六爻七位合参 V1.0（Android APK）

## 核心规则
七星彩不是旧式“七个0—9”，而是：**前六位各0—9，第七位0—14**，一注为6位数字加最后一位，共1000000×15=15000000种。中国体育彩票官方玩法： https://www.sporttery.cn/help/2857.html?gid=1 。

## 7星彩与第七位的特殊处理

前六位为0..9，**第七位单独为0..14**，0至14均作为完整数字输出（可能是10、11、12、13、14，而不拆成两位）。UI显示举例 `123456+07` 或 `123456+14`。第七位从主爻取数、本变卦上下数、动爻数、干支总数等派生整数，按mod 15生成每方法最多4候选。不是把第七位从第六位复制，也不会把14错拆为1、4。

## 七位模型和复式上限

各术数独立输出每位4候选；合参按加权得分逐位各取4个；可以在界面手工更改，1至4个且不能重复，越界拒绝；变化后重算前20的综合分。组合数为7个位候选数之积，最大4^7=16384组。最多全复式按2元/注名义需要32768元，而且超过单张彩票20000元最高票面金额，**并不建议购买这个全复式**。数学基线：单个完整开奖号码1/15000000；16384组合理论全部号码命中覆盖0.1092267%，任何占卜数理方法均无可靠证据能改变随机开奖的概率。

## 盲测及复盘

- 支持北京时间固定起盘和随机盘，随机种子可复用，每次重新起盘更新。
- 期次自行输入；冻结时保存所有7位综合候选、7家各自候选、原排盘全文、日期、Seed、SHA-256，不允许对相同期次覆盖预测。
- 开奖后手输如 `123456+14`，软件分别给出综合7位覆盖和各家7位覆盖，累计统计亦只读取已冻结并复盘记录。
- **不联网获取开奖数据、不自动核验官方结果**；SHA-256仅防止误修改快照，不是可信的第三方时间戳。安卓本地数据如卸载应用可能丢失。
- 保存上限为500期，避免无限增长。当前不导入历史开奖、不训练和修改权重。

## 构建

工作目录 `qixingcai-liuyao`；Android Gradle Plugin 8.7.3、Gradle 8.9、Java17、compileSdk35、minSdk26、targetSdk32；依赖`cn.6tail:lunar:1.7.7`。复用旧项目六爻排盘源文件并将包名调整为`com.abe618.qixingcai`。独立安装包名：`com.abe618.qixingcai.hexfusion.v1`。

CI 路径`.github/workflows/qixingcai-liuyao-android.yml`，生成调试签名APK并校验 APK ZIP完整性、aapt安装包元信息、apksigner 和 zipalign。CI编译成功不等于已经在真实手机完成全部交互测试。

**警告**：不应将术数排序、中奖彩票复盘个例或小样本命中率解释为提高中奖概率、保障盈利；不向未成年人销售彩票。
