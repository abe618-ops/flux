# 四彩术数合参 V2（研究/盲测版）

目标：在既有项目上统一福彩快乐8、福彩3D、体彩排列3、体彩排列5的术数排盘、历史盲测和可复现随机框架。保留“先冻结、后开奖、再复盘”的研究流程，不把术数映射表述为确定性预测。

## 1. 直接复用的既有底座

- `lottery-blind-backtest`：真实历史开奖同步、严格校验、盲投/揭晓、数据清单、Android 构建。
- `p3p5-fast-check`：排列3/5真实开奖查询与本地缓存。
- “三术数研”既有内核：奇门遁甲 + 大六壬 + 六爻纳甲，三术独立输出后合参。
- 既有随机规范：固定 Seed 可完整复现；不同术数使用独立随机流；保留起盘时间、种子、算法版本、审计号。
- 既有回测规范：开奖前冻结，开奖后结算；失败、冲突和未命中样本全部保留。

## 2. 本版固定三个维度

每一期、每个彩种都生成三套彼此独立的盘面，不互相倒推：

### A. 时间盘
按该彩种当期正式开奖时刻起盘。已有研究中：
- 福彩3D：21:15
- 排列3 / 排列5：21:25
- 快乐8：由官方开奖日历/数据同步模块读取并校验，不在代码里凭经验硬编码。

### B. 随机数盘
- 系统安全随机源生成 256 位主 Seed；
- HMAC-SHA-256 为奇门、六壬、六爻分别派生独立子 Seed；
- 所有抽取使用拒绝采样/Fisher-Yates，避免简单取模偏差；
- 支持用户手输数字/文字作为固定 Seed；
- 同一 Seed + 同一算法版本必须得到完全相同结果。

### C. 当日活时盘
- 只在目标开奖日内取时；
- 默认从当天 00:00 到开奖前的有效分钟中等概率抽取一个“活时”；
- 活时一经生成立即冻结；
- 可手动“再取一次活时”，但每次都留下审计记录，回测时不得删除不利样本。

## 3. 术数内核

V2 首版保持可比性，核心仍采用：
1. 奇门遁甲
2. 大六壬
3. 六爻纳甲

三术先独立取数，再在每个维度内部合参；三个维度最后再做二次合参。

辅助术数暂作为可开关实验层，不直接改变首版主权重：
- 梅花易数
- 太乙
- 河洛数
- 九爻易
- 灵棋经

只有经过固定样本盲测后，才允许改变权重。

## 4. 四彩分别输出

### 福彩3D / 体彩排列3
- 百位、十位、个位：每位 Top3 / Top5
- 直选候选 Top N
- 组选候选
- 和值
- 跨度
- 奇偶结构
- 大小结构
- 012 路
- 三维一致号码 / 两维共振号码

排列3继续遵循“以同期开奖排列5前三位作为开奖号码”的官方规则。

### 体彩排列5
- 5 个位置分别给 Top3 / Top5
- 位置概率/评分矩阵：5 × 10
- Top10 / Top100 / Top500 组合
- 和值、奇偶、大小、重复位结构
- 前三位同步生成“排列3视图”，便于同一期联合回测

### 福彩快乐8
沿用此前九宫取数思路，但不直接把九宫频率当作概率：
- 1–80 映射九宫
- 每个术数独立形成宫位强弱和号码评分
- 输出：核心8、核心12、扩展20、杀号区
- 输出奇偶比、区间比（1–20 / 21–40 / 41–60 / 61–80）、尾数结构、宫位集中度
- 三维合参后生成“共振号码池”
- 继续保留此前快乐8九宫回测中的收缩思想，避免小样本宫位波动被过度放大

## 5. 两级合参

第一级：单维度内“三术合参”
- 三术等权起步；
- 3术同向/同号 = 强共振
- 2术一致 = 弱共振
- 三术分散 = 不强行给结论

第二级：时间盘 / 随机数盘 / 当日活时盘三维合参
- 3维一致：一级共振
- 2维一致：二级共振
- 1维独立：只展示，不纳入主推池
- 首版三个维度等权，不根据单次结果临时调权

## 6. 盲测与权重升级

固定流程：
1. 选择历史一期；
2. 隐藏开奖结果；
3. 生成三维盘面；
4. 冻结盘面、Seed、时间、算法版本与输出；
5. 点击“揭晓”才读取真实结果；
6. 自动结算；
7. 写入不可删除的回测记录。

统计：
- 3D/P3：位置 Top-K、直选、组选、和值、跨度、结构命中
- P5：逐位 Top-K、整组 Top10/100/500覆盖
- 快乐8：核心8/12/20命中个数、随机基线对照、各区/各宫覆盖
- 每个术数、每个维度、最终合参分别统计
- 必须同时保留随机基线 L0；只有长期盲测明显优于基线，才允许讨论增权

## 7. 数据规则

V2 不复制旧版本中未经核验的开奖记录。

数据层直接继承 `lottery-blind-backtest` 的原则：
- 构建前同步真实历史开奖；
- 期号、日期、号码交叉校验；
- 校验失败则构建失败；
- APK 内保存数据 manifest；
- 离线只读取最后一次通过校验的快照。

## 8. Android 页面

首页四个彩种 Tab：
- 快乐8
- 福彩3D
- 排列3
- 排列5

每个彩种首屏固定显示：
- 当期/历史期号
- 三个大按钮：时间盘｜随机数盘｜当日活时盘
- “三维合参”置顶结果
- 共振等级
- 主号码池 / 扩展号码池
- Seed / 起盘时刻 / 算法版本
- “冻结”
- “揭晓”
- “下一期盲测”

下方再展开：
- 奇门盘
- 六壬盘
- 六爻盘
- 单术取数解释
- 历史统计

## 9. V2 首轮开发顺序

1. 从 `lottery-blind-backtest` 拆出统一开奖数据接口；
2. 接入 3D/P3/P5 已有三术内核；
3. 完成三个维度统一 Seed/时间审计；
4. 完成快乐8 1–80 九宫映射；
5. 做历史盲测与随机基线；
6. 最后再根据盲测结果决定是否启用梅花/太乙/河洛等辅助术数。

> 本项目定位为传统术数、随机算法与历史盲测研究工具。彩票开奖结果具有随机性，任何术数映射都不应被表述为保证中奖或稳定收益的方法。
