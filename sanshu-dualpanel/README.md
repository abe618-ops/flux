# 三术数研 · 双维一致连续抽取版

基于用户提供的“三术数研.apk”改造。原 APK 的三术排盘与取数内核保持不变：`traditional-engine.js` 与 `number-core.js` 未修改；新增逻辑只读取原有输出，在 UI/结果层完成双维判断、连续随机与足球粗估展示。

## 双维判断规则

1. **维度1：百位 vs 个位**  
   读取原程序“分位候选”中百位前三候选数字之和与个位前三候选数字之和。  
   `百位和 - 个位和 >= 5` → 上盘；`<= -5` → 下盘；绝对差值小于 5 视为接近，不触发。

2. **维度2：奇门 vs 六爻**  
   读取原程序奇门遁甲前五候选数字之和、六爻纳甲前五候选数字之和。  
   `奇门和 - 六爻和 >= 5` → 上盘；`<= -5` → 下盘；绝对差值小于 5 不触发。

3. **连续随机**  
   随机模式自动连续抽取；只有两个维度都达到阈值且方向一致时才停止，并以最后一次抽取为最终结果。为防异常设 500 次保底上限。用户填写复现种子时，后续每一轮从基础种子确定性派生，可复现整个连续抽取过程。

4. **足球粗估**  
   最终结果卡片置顶显示：上盘/下盘、两维原始和与差值、连续抽取次数、让球粗估、总进球区间和比分粗估。足球部分只按最终两维差值强度做区间映射，不反向改变原三术排盘。

## 验证

2026-09-18 对排列3、福彩3D、排列5各运行 30 组随机种子，共 90 组，均在 500 次以内触发双维一致；该验证只确认程序逻辑和终止性，不代表任何真实赛事或开奖预测能力。
