# 四术足球盲测 Android v0.2

v0.2 的目标不是增加更多术数，而是让软件内核与聊天中的人工合参流程保持一致。

## 四术
- 玛雅 Tzolk'in
- Sikidy
- Ifá
- 阿拉伯沙占 / Raml

## v0.2 核心变化

### 1. 方向不再简单多数票
先统计主/平/客票数，再比较每一票的强弱幅度。结果直接输出：

- 主线方向排序，例如：平 > 主胜 > 客胜
- 更稳结构，例如：主队不败、重点防平
- 主方向倾向度（内部一致度，不是真实概率）

### 2. 强冲突单独处理
如果多数票与沙占强反向信号冲突，而且整体强度被拉回均衡区，不再直接跟多数票，而是提高“平局”权重。

这对应当前人工合参中“主2票、平1票、客1票，但沙占强客/零封，把主客差距拉平”的处理方式。

### 3. Ifá 的单边信号与方向分离
Ifá 高度集中只解释为“单边化/后程增强”，不再直接指定是哪一边爆发。

### 4. 爆发分支
Ifá 集中 + 沙占前静后强同时出现时，强制保留：

- 3:0 / 0:3
- 3:1 / 1:3

这类比分，避免样本007式的 0:3 被低比分结构完全排除。

### 5. 沙占零封成为“冷防层”
沙占出现强方向 + 零封时，如果它与主线冲突，不再强行覆盖主线，而是单列：

- 0:1 / 0:2
- 1:0 / 2:0

作为冷防。这与样本009的人工判断一致。

### 6. 进球数与方向分开判断
先看四术进球票：
- 4个都 ≥3：3–4球，偏大球。
- 3个 ≥3：2–4球，大球偏强。
- 2大2小：按主方向是否平局、Sikidy稳定、沙占收束判断2球还是3球。
- 3个以上 ≤2：偏小球。

### 7. 比分分三层
首页显著显示：
- 首选比分
- 次选比分
- 冷防比分

不是把所有比分混成同一层。

## 复盘
冻结样本保存 Seed。赛后录入比分时按冻结 Seed 重建原盘，核对：
- 主方向
- 大小2.5
- 单双
- 总进球区间
- 比分候选

## 构建
```bash
gradle :app:assembleDebug
```

`dist/FourDivinationFootball-v0.2-debug.apk`

`com.abe618.fourdivfootball`
