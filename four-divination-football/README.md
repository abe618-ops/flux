# 四术足球盲测 Android v0.1

基于当前连续盲测过程制作的本地实验 APK。四套体系独立起盘：

- 玛雅 Tzolk'in 260 日历：13 数 × 20 日符。
- 马达加斯加 Sikidy：四母起局、奇偶派生。
- Ifá：8 位二元签名，对应 256 种组合索引。
- 阿拉伯沙占 Ilm al-Raml：四母 → 女儿 → 侄 → 见证 → 法官。

## 界面重点

合参预测置于首页最上方大卡片，优先显示：

胜平负 / 不败方向 / 半全场 / 进球范围 / 大小2.5 / 单双 / 首选比分 / 4 个比分候选。

四术独立盘面放在其后，避免明细遮挡最终结果。

## 当前迭代规则

1. 四术原始起盘保持独立等权，不因上一场赛果临时改盘。
2. 沙占零封信号单独记录。
3. Ifá 高度集中 + 沙占“前静后强”时开启 3:0 / 0:3 单边爆发分支。
4. Sikidy 稳定/双数象不再自动解释为小球；若与爆发信号冲突，保留 3–4 球比分。
5. 支持冻结样本。冻结后通过 Seed 完全复现，赛果录入不会修改原预测。
6. 本机保存近期复盘：方向、大小、单双、进球区间、比分候选逐项 ✓/×。

## 构建

```bash
gradle :app:assembleDebug
```

GitHub Actions 构建后把 APK 写到：

`dist/FourDivinationFootball-v0.1-debug.apk`

包名：`com.abe618.fourdivfootball`，与此前软件可并存。

> 用途：术数盲测、规则冻结和统计实验。传统占卜体系与足球赛果之间没有已建立的科学预测关系；应用中的足球映射和“倾向度”属于实验模型，不是现实概率。
