# v0.1 冻结模型

## 一、随机与复现

一次主 Seed 派生四个独立子 Seed，分别用于 Tzolk'in、Sikidy、Ifá、Raml。相同 Seed 必须得到完全相同的四盘和合参输出。

## 二、独立盘

### Tzolk'in
随机定位 1–260，并拆为 1–13 数值和 20 日符。足球主客、进球数映射是本项目的固定实验映射，不宣称是传统玛雅足球占法。

### Sikidy
只随机四母。女儿、后续图形全部由四母的奇偶结构派生；重点记录稳定象、单双结构，但根据样本007复盘，稳定/双数不再自动等于低比分。

### Ifá
使用 8 位二元签名并保存 1–256 实验索引。连续位高度集中时只判“单边化/后程增强”，不再直接把单边化强行归到主队或客队。

### Raml
四母独立随机，后续图形按奇偶/XOR派生。单独提取“后程收束/零封”和“前静后强/爆发”标签。

## 三、合参

- 四术方向等权投票，并参考标准化 margin。
- 四术进球中心取平均后再应用冲突规则。
- Ifá 集中 + Raml 前静后强：开启爆发反转分支，比分候选强制加入 3:0/0:3 一类比分。
- Raml 零封 + 至少一个同方向支持：开启零封分支，优先加入 1:0/2:0 或 0:1/0:2。
- 均衡且低进球：1:1 分支前置。
- “合参倾向度”只度量四盘内部一致性，最大值限制在 84，不作为真实比赛概率。

## 四、冻结与复盘

冻结样本只保存 Seed + 名称。复盘时由 Seed 重新生成原盘，逐项核对：

- 胜平负
- 大小2.5
- 单双
- 总进球中心 ±1 区间
- 比分候选

这样避免赛后人工改盘。
