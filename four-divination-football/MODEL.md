# v0.2 分层合参内核

## 总原则
四术先独立，合参后解释。禁止赛果出来后改 Seed、改原盘或倒推规则。

## 一、方向层
1. 统计主/平/客票数。
2. 计算每票强度，沙占方向权重略高，但不能直接覆盖其他三术。
3. 3票以上同向：该方向主线。
4. 主客2:2：比较两边强度；强度差小则平局前置，差明显则强侧主线。
5. 2-1-1：多数方向先占优；若沙占为强反向且整体强度接近零，则平局前置，多数方向退为第二。
6. Ifá集中只作为“单边化”结构，不直接给某一边额外方向权。

## 二、进球层
- 4个高球：3–4球。
- 3个高球：2–4球。
- 2高2低：如果平局/稳定/收束较强，2球优先；否则3球优先。
- 3个低球：小球优先。
- Ifá集中+沙占前静后强：3球起步，并保留4球。

## 三、单双
4-0 = 明显；3-1 = 偏强；2-2 = 弱信号，仅按核心进球奇偶给轻微参考。

## 四、比分
输出三层：
- 首选：主线方向 + 核心进球。
- 次选：相邻结构。
- 冷防：沙占强反向零封、爆发分支或低频结构。

## 五、半全场
- 平局主线：平/平第一，平/次方向第二。
- 非平主线且3票以上同向：同向/同向第一。
- 其他非平主线：平/主线第一，同向/同向第二。

## 六、样本经验已写入
- 3:0/0:3 必须在爆发分支里有位置。
- 1:1 均衡低比分必须能成为首选，不只放冷防。
- Sikidy稳定/双数不能直接推出小球。
- 沙占强零封若和主线冲突，进入冷防层，不强行覆盖主线。
