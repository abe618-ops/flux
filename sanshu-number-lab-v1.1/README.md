# 三术数研 · 排列3/排列5 九宫历史校准 v1.1

本分支记录对“三术数研”排列3／排列5取数内核的 1.1 优化。完整可运行源码快照同时保存在用户文件库：
`三术数研_排列3排列5_九宫历史校准_v1.1_source.zip`。

## 数据依据

用户提供 2026-06-19 至 2026-09-26 共 100 期快乐8“奇门九宫—出号”样本。外八宫共 800 个“宫×期”记录：

- 平均每外宫出号数：2.01375
- 活跃率（出号 >= 3）：0.32375
- 中五宫容量不同，不参与外八宫校准
- N < 10 的组合不进入模型
- 相关性不解释为因果，也不把 lift 当作排列3／排列5开奖概率

截图中“全局均值 0.32 个”把两个指标混在了一起：0.32 对应活跃率；平均出号数约为 2.01。本版分开处理。

## 进入低权重校准的单条件

| 条件 | 平均出号 lift | N |
|---|---:|---:|
| 地盘干=丁 | 1.15 | 90 |
| 八神=值符 | 1.12 | 100 |
| 八门=景门 | 1.14 | 100 |
| 八神=九天 | 1.07 | 100 |
| 天盘干=己 | 1.06 | 90 |
| 天盘干=辛 | 0.88 | 90 |
| 旬空 | 0.94 | 180 |
| 八神=太阴 | 0.92 | 100 |
| 八神=玄武 | 0.87 | 100 |

“八神=值符”与“值符临宫=1”在当前数据结构中是同一事实，因此只计一次，避免重复放大。

## 可稳定复算的双条件

- 天盘干=己 + 宫生星：lift 1.29，N=15
- 地盘干=丁 + 驿马：lift 1.39，N=15

截图中“地盘丁+天盘干月令废”“地盘己+九星月令休”“景门+天盘干月令废”等条件没有硬编码，因为当前排盘对象没有暴露与历史文本完全同口径的逐宫月令状态。宁可暂缺，也不靠猜测映射。

## 校准公式

每条规则先做样本量收缩：

```
delta = (lift - 1) * N/(N+50) * 4
```

同一宫所有命中规则相加后限幅在 `[-0.80, +0.80]`。

- 奇门全局层使用 0.55 倍 delta
- 奇门分位落宫使用 1.0 倍 delta
- 六壬、六爻不被此历史层修改
- 三术总权重仍保持 1/3 + 1/3 + 1/3

## 结构性修复

上一实验版把“连续随机直到双维同向且差值 >= 5”设为默认，这会产生明显的筛选偏差。v1.1 已改为：

1. 默认恢复“开奖时刻”
2. “完全随机”只抽取一次随机分钟 + 六次三钱，可由同一种子复现
3. 不再最多循环 500 次寻找内部满足条件的结果
4. 足球让球／比分粗估区块不参与排列3／排列5数字内核，界面默认隐藏
