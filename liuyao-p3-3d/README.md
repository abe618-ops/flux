# 六爻排列三·定胆定位 V3.0

本版复用原六爻三位数 Android 工程，在原纳甲排盘上加入完整天干/地支太玄数、河图取数、双卦对照、分位四码保护、独立组选与冻结复盘，作为传统象数的离线实验工具。安装包名为 com.abe618.liuyaopick3.hexp3v3，Android 8.0 及以上，和 V2.1 独立并存。应用入口 V3Activity.java，新评分核心 HexP3V3.java，原刘爻基础 LiuyaoEngine.java 保持。

## 方法结构

六爻本体优先：传统铜钱六爻 6/7/8/9、八宫世应、纳甲支、六亲六神、月日旺衰、旬空、冲合墓、旺动候选来自旧版引擎；增加纳甲天干太玄数（甲己9、乙庚8、丙辛7、丁壬6、戊癸5），地支太玄数（子午9、丑未8、寅申7、卯酉6、辰戌5、巳亥4）；河图（水1/6、火2/7、木3/8、金4/9、土5/0）以及后天卦数。六爻 5/6 爻→百位、3/4 爻→十位、1/2 爻→个位是用于取数的现代约定，并非可验证的传统彩票开奖公式。

只统计同名外部术数一次；本主盘评分权重大于辅助盘，且外部术数不能挤掉原六爻评分。每位选四码时，先保留最高两码，第三码优先保护原六爻数字，第四码优先保护其它来源；有位次约束则仅从满足条件的号码里筛选。

软件同时显示原始六爻独胆、综合独胆/双胆/三胆、各位四码、Top 直选及完整复式；原六爻组选组合独立保存，不受最终位置四码限制。组三/组六/豹子全部参与，不把某几期开奖结果当成模型权重提高的理由。

## 操作

启动自动使用北京时间生成正时盘。支持正时盘、随机盘、正时+随机辅助双盘、活时盘、随机下一盘。日期和期次可自行更改；随机起卦的 Seed 会显示并保存；三位号输入支持 0 开头。

按「冻结本期」保存一条不可覆盖的原预测快照，包含详细盘面、原始与压缩后四码、全集最多64组、原始组选、SHA-256及起盘信息。按「按冻结快照复盘」输入开奖结果，比对准确的是事前快照而非当前盘；同一期只记一次，统计原始独胆、综合独胆、各位置四码、直选、组选。

历史已知案例可供人工回放：2026179 期396、10月21日864、10月22日983、10月23日647、10月24日258、10月25日677；这些已知结果**不参与新模型权重训练**，仅用于分析预测前后的损失与事前冻结规范。

## 实验边界

当前使用离线输入，不联网查询彩票开奖号码，也不自动取得官方比赛结果。模型数字排序不代表开奖的真实概率。各个指定三位直选的理论概率为0.1%；随机单胆三位至少出现一次为27.1%，每位四码最多64组直选为6.4%。传统六爻、太玄及多术合参尚无可靠证据能提高中奖率。

项目 CI：.github/workflows/liuyao-p3-3d-android.yml；Android SDK35、Java17、minSdk26。构建成功后由 CI 验证 APK 签名与 ZIP 对齐。GitHub 调试签名可能变化，故采用独立应用 ID。

## 首页和操作
- 启动后默认按本机日期/时间起盘，顶部显示原始单胆与条件单胆、百十个位候选、直选 Top12、组选以及符合条件的组合总数。
- 时间盘、随机盘、活时盘（可记录复现 Seed）。原六爻旺衰、世应、妻财、动变等计算不移除。
- 各位置独立大小单双筛选：不限、大单、大双、小单、小双、大、小、单、双；支持额外指定位置候选号，例如百位 `7,9`、十位 `2,4,8`、个位 `3,5,7,9`。
- 外部九家术数投票可按 `方法名:百候选|十候选|个候选` 逐行粘贴，如 `太玄:4,6,7|0,2,1|5,8,1`。内置的2026年10月22日候选仅作为历史示例，**不要跨日期复用**。
- 保存原始卦/条件筛选与外部投票的 SHA-256 本地校验码、最后冻结快照与冻结历史索引；事后重筛不可充当事前预测。
- 原始六爻盘及逐术明细默认折叠，展开可读；可手输开奖复盘。

## 新内核的明确边界
- 后天卦数：坎1、坤2、震3、巽4、乾6、兑7、艮8、离9；先天卦数单列低权。
- 河图五行：水1/6、火2/7、木3/8、金4/9、土5/0；动爻加权。
- 太玄取数当前使用**地支部分**：子午9、丑未8、寅申7、卯酉6、辰戌5、巳亥4；并非完整的天干纳甲太玄公式。
- 九术投票由用户输入，每家每个位次记一次覆盖；旧引擎、八卦、河图、地支太玄、投票数分层记分。
- “原始单胆”与“条件单胆”同时显示；设置位置条件不会回写原始盘。
- 直选包含组六、组三、豹子，所有1000组均被考虑，不因个别历史中奖事后强行提高重号权重。
- 复式筛选属于条件枚举，不代表实际开奖概率增加。

## V1 原版技术记录

# 六爻三位数研究 V1（排列3 / 福彩3D）

这是一个**单独的六爻 Android 研究工具**，从此前的“三术数研 / 四彩术数合参 / P3P5 Fast Check”中抽取了可复现起盘、独立包名、冻结审计和开奖后复盘技术，但本版只保留六爻体系。

## 已融入的取数思路

1. **妻财为号码本体**：妻财爻高权重。
2. **应爻为彩票中心/开奖方**：应爻与妻财并列核心来源。
3. **世爻为求测方与结果承受方**：中等权重。
4. **旺动爻为信息枢纽**：动而旺者继续增权。
5. **五行旺衰取数**：
   - 旺相：水6、火7、木8、金9、土5；
   - 休囚：水1、火2、木3、金4、土0。
6. **0 的两个独立来源**：
   - 土五行休囚取0；
   - 旬空取0。旺空则保留本五行数，同时弱辅0；弱空则0优先。
7. **生克冲合墓化关系链**：
   - 临月建时读取农历月序；
   - 动爻变支读取变支序数；
   - 六合取合支序数；
   - 六冲、入墓做关系候选；
   - “冲+墓”保留为实验复合规则；
   - 核心爻生出他爻时，强化核心五行本数。
8. **卦名/字形机锋实验层**：
   - 与直接五行数分层；
   - 当前把已经讨论过的《雷山小过》《天风姤》作为低权案例规则；
   - 只有与其他通道重复时才升权。
9. **结构层**：
   - 全局胆码 Top6；
   - 百十个位 Top5；
   - 直选 Top20；
   - 组选 Top12；
   - 和值 Top5；
   - 跨度、奇偶、大小。
10. **共振评分**：同一个数字由妻财、应爻、旺动、月序、变支、冲合墓、生克、卦名等多路重复指出时自动加权。

## 起盘方式

- **时间盘**：使用指定日期和时刻，可完全复现。
- **随机数盘**：空 Seed 时用 256 位安全随机主 Seed；手输数字/文字时可复现。
- **当日活时盘**：在当日 00:00 至开奖时刻前随机取一个有效分钟；福彩3D默认21:15、排列3默认21:25。

## 纳甲与六亲

- 六爻按三枚铜钱法生成 6/7/8/9；
- 使用八宫世应定位；
- 使用常见纳甲地支表；
- 六亲按卦宫五行与纳甲地支五行生克确定；
- 六神按日干起青龙/朱雀/勾陈/螣蛇/白虎/玄武；
- 旺衰目前以月建、日建、月日生克、月破日冲、动静、旬空综合打分。

## 研究纪律

软件把以下层级**分开统计**：
- 候选数字覆盖；
- 组选覆盖；
- 定位 Top-K；
- 直选 Top20；
- 和值。

使用“事前起盘 → 冻结 → 开奖 → 复盘”的流程，冻结时保存完整 Seed、文本快照和 SHA-256 审计号，避免开奖后倒推规则。

> 彩票结果具有随机性。本项目用于传统六爻、象数规则和历史盲测研究，不提供投注、购买或保证中奖功能。
