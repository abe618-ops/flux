# 排列3 · 六爻九术合参 V2.1（Android 离线研究版）

独立应用 ID：`com.abe618.liuyaopick3.fusionv21`，Android 8.0+。本版从原六爻三位数工程迭代而来，可与旧版本并存。

## 首页和操作
- 启动后默认按本机日期/时间起盘，顶部显示原始单胆与条件单胆、百十个位候选、直选 Top12、组选以及符合条件的组合总数。
- 时间盘、随机盘、活时盘（可记录复现 Seed）。原六爻旺衰、世应、妻财、动变等计算不移除。
- 各位置独立大小单双筛选：不限、大单、大双、小单、小双、大、小、单、双；支持额外指定位置候选号，例如百位 `7,9`、十位 `2,4,8`、个位 `3,5,7,9`。
- 外部九家术数投票可按 `方法名:百候选|十候选|个候选` 逐行粘贴，如 `太玄:4,6,7|0,2,1|5,8,1`。内置的2026年10月22日候选仅作为历史示例，**不要跨日期复用**。
- 保存原始卦/条件筛选与外部投票的 SHA-256 本地校验码、最后冻结快照与冻结历史索引；事后重筛不可充当事前预测。
- 原始六爻盘及逐术明细默认折叠，展开可读；可手输开奖复盘。

## 新内核的明确边界
- 后天卦数：坎1、坤2、震3、巽4、乾6、兑7、艮8、离9；先天卦数单列低权。
- 河图五行：水1/6、火2/7、木3/8、金4/9、土5/0；动爻加权。
- 太玄取数当前使用**地支部分**：子午9、丑未8、寅申7、卯酉6、辰戌5、巳亥4；并非完整的天干纳甲太玄公式。
- 九术投票由用户输入，每家每个位次记一次覆盖；旧引擎、八卦、河图、地支太玄、投票数分层记分。
- “原始单胆”与“条件单胆”同时显示；设置位置条件不会回写原始盘。
- 直选包含组六、组三、豹子，所有1000组均被考虑，不因个别历史中奖事后强行提高重号权重。
- 复式筛选属于条件枚举，不代表实际开奖概率增加。

## 可重复构建

`gradle -p liuyao-p3-3d assembleDebug`，自动构建见 `.github/workflows/liuyao-p3-3d-android.yml`。构建脚本验证 APK 文件、Android 包信息、签名与 zipalign。

> 本工具是传统象数和随机数研究实验，不联网抓取开奖号码、不接入投注平台，不承诺提高中奖概率。调试版由 GitHub Actions 签发临时调试证书；后续调试构建可能使用不同签名，因此新版本刻意采用独立包名以避免覆盖冲突。

## V1 原版技术记录

# 六爻三位数研究 V1（排列3 / 福彩3D）

这是一个**单独的六爻 Android 研究工具**，从此前的“三术数研 / 四彩术数合参 / P3P5 Fast Check”中抽取了可复现起盘、独立包名、冻结审计和开奖后复盘技术，但本版只保留六爻体系。

## 已融入的取数思路

1. **妻财为号码本体**：妻财爻高权重。
2. **应爻为彩票中心/开奖方**：应爻与妻财并列核心来源。
3. **世爻为求测方与结果承受方**：中等权重。
4. **旺动爻为信息枢纽**：动而旺者继续增权。
5. **五行旺衰取数**：
   - 旺相：水6、火7、木8、金9、土5；
   - 休囚：水1、火2、木3、金4、土0。
6. **0 的两个独立来源**：
   - 土五行休囚取0；
   - 旬空取0。旺空则保留本五行数，同时弱辅0；弱空则0优先。
7. **生克冲合墓化关系链**：
   - 临月建时读取农历月序；
   - 动爻变支读取变支序数；
   - 六合取合支序数；
   - 六冲、入墓做关系候选；
   - “冲+墓”保留为实验复合规则；
   - 核心爻生出他爻时，强化核心五行本数。
8. **卦名/字形机锋实验层**：
   - 与直接五行数分层；
   - 当前把已经讨论过的《雷山小过》《天风姤》作为低权案例规则；
   - 只有与其他通道重复时才升权。
9. **结构层**：
   - 全局胆码 Top6；
   - 百十个位 Top5；
   - 直选 Top20；
   - 组选 Top12；
   - 和值 Top5；
   - 跨度、奇偶、大小。
10. **共振评分**：同一个数字由妻财、应爻、旺动、月序、变支、冲合墓、生克、卦名等多路重复指出时自动加权。

## 起盘方式

- **时间盘**：使用指定日期和时刻，可完全复现。
- **随机数盘**：空 Seed 时用 256 位安全随机主 Seed；手输数字/文字时可复现。
- **当日活时盘**：在当日 00:00 至开奖时刻前随机取一个有效分钟；福彩3D默认21:15、排列3默认21:25。

## 纳甲与六亲

- 六爻按三枚铜钱法生成 6/7/8/9；
- 使用八宫世应定位；
- 使用常见纳甲地支表；
- 六亲按卦宫五行与纳甲地支五行生克确定；
- 六神按日干起青龙/朱雀/勾陈/螣蛇/白虎/玄武；
- 旺衰目前以月建、日建、月日生克、月破日冲、动静、旬空综合打分。

## 研究纪律

软件把以下层级**分开统计**：
- 候选数字覆盖；
- 组选覆盖；
- 定位 Top-K；
- 直选 Top20；
- 和值。

使用“事前起盘 → 冻结 → 开奖 → 复盘”的流程，冻结时保存完整 Seed、文本快照和 SHA-256 审计号，避免开奖后倒推规则。

> 彩票结果具有随机性。本项目用于传统六爻、象数规则和历史盲测研究，不提供投注、购买或保证中奖功能。
