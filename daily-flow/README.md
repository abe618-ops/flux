# Daily Flow / 每日行动账

一个本地优先、无需登录、无需 Token 的 Android 每日任务管理工具。目标是把「计划 → 提醒 → 番茄专注 → 完成反馈 → 每日记录 → 日记导出」放在一个尽量少点击的界面里。

## v0.1.0 已实现

- 一句话快速输入：支持 `30分钟后整理资料`、`下午3点还款100元`、`明天9点写文章` 等基础时间表达。
- 系统语音识别：说完后直接建立任务，尽量减少点击。
- 三类记录：任务、备忘、每日点子/灵感。
- 简单行动账：自动识别存款、还款、收入、支出金额，并写入当天日记。
- 番茄钟与任务绑定：5/10/15/20/25/30/40/50/60 分钟，以及 2/3/8 小时快捷时长。
- 闹钟式提醒：声音、振动、高优先级通知、全屏提醒页，提供醒目的“一键关闭提醒”大按钮。
- 可选桌面滚动提醒：授权“显示在其他应用上层”后，闹钟触发时在屏幕顶部显示滚动任务条和关闭按钮。
- 每日完成统计：完成数、番茄数、专注分钟数、行动账金额。
- 自动生成“每日行动账”，并支持复制全文、导出 Markdown、TXT、DOCX。
- 本地 SQLite 保存，不依赖服务器。
- 重启手机后会重新挂载尚未到期的任务提醒。

## 页面

1. **今天**：快速输入、语音、今日任务、备忘、点子、完成反馈。
2. **番茄**：默认时长选择和当前专注倒计时。
3. **记录**：当天执行账预览、复制和 MD/TXT/DOCX 导出。
4. **设置**：精确闹钟、桌面滚动提醒、全屏闹钟权限状态。

## Android 权限说明

为了实现“真正能听见/看见”的提醒，首次使用建议在“设置”页检查：

- 通知权限
- 精确闹钟权限
- 全屏闹钟权限（Android 14+）
- 显示在其他应用上层（仅用于用户主动启用的顶部滚动提醒）

即使不授予悬浮权限，任务仍可以使用通知、声音和振动提醒。

## 构建

项目使用纯 Android SDK Java 实现，没有第三方运行时依赖。仓库保存源码归档分片，GitHub Actions 构建时会自动还原完整 Android 工程。

GitHub Actions 会自动构建 debug APK，并上传为 `DailyFlow-v0.1.0-debug` artifact。

## 当前边界

v0.1.0 优先保证本地任务、番茄、提醒和导出闭环。后续可继续加入：历史日历、任务延期/顺延、按周/月统计、更多自然语言时间表达、自定义激励语、数据备份与恢复。
