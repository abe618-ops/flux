# 四层随机足球预测 V2

本版本在 V1 排盘内核上新增“无需输入现实时间”的随机起盘足球盲测层。

## 随机机制

- 每次点击“下一场 · 安全随机起盘”，由 Android `SecureRandom` 生成 256 位主种子。
- 四个层级通过 `SHA-256(masterSeed || label)` 分别派生，避免四盘直接复用同一串随机值。
- 界面显示封盘 ID，并可复制完整 256 位种子，便于复盘和核验。
- 纯软件无法从数学上证明“绝对随机”，因此这里使用操作系统提供的密码学安全随机源，不使用 `java.util.Random`、时间戳或自增序号充当随机数。

## 四层盘

1. **时家盘**：V1 时家奇门拆补转盘。
2. **刻家盘**：10 分钟一柱的刻家口径。
3. **分盘**：4 分钟一柱的实验细分口径。
4. **秒盘**：20 秒一柱的实验细分口径。

分盘与秒盘属于流派差异较大的细时间扩展，因此代码中明确标成实验口径；后续可根据已知盘逐例校准。

## 足球输出

每盘独立给出：

- 胜平负
- 半全场
- 进球数
- 比分（主选 + 备选）
- 大小球 2.5
- 单双

总体合参暂采用四层等权，不提前人为提高某一层权重；后续依据冻结盲测结果再调整。

## V2.1 计划

- 保存历史封盘与真实比分
- 自动复盘每一项命中率
- 时/刻/分/秒四层独立统计
- 2/4、3/4、4/4 共振统计
- 根据盲测样本训练权重，但不修改历史封盘
- 加入让球胜负与净胜球区间
