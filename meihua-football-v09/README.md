# 梅花足球合参 V0.9

Android 16 / SDK 36 原生 Java 实验版。

## 功能

- 随机起盘、时间起盘、手工录入盘面。
- 五个位置：万、元、会、运、世。
- 策数 / 轨数与五行均可手工修改，便于复刻截图样本。
- 数字按八卦取象：1乾、2兑、3离、4震、5巽、6坎、7艮、8/0坤，9循环到乾，再映射五行。
- **合参结果置顶大字显示**。
- 输出：胜平负、总进球中心与范围、大小2.5、单双、双方进球、半场、半全场、比分候选、模型权重。
- 可录入真实赛果，本机持续统计胜平负、总球、范围、精确比分、单双、大小命中。

## V0.9 内核

当前对话迭代形成的实验逻辑：

1. 强激活 A：同位策轨数字绝对差 >= 3。
2. 总进球主体：以 A 为中心。
3. 克制 K 压缩：K=3 时 A-1；K>=4 时 A-(K-1)。
4. 无克扩张：K=0、A>=4 且强点至少 75% 集中一侧时 +1。
5. 比分分配：强点归属优先；A=2 且一边一个强点时优先 1:1。
6. 零值、核心三区、总量、生克关系作为方向和零封修正。
7. 保留本轮样本出现的“双零断裂”和“单零反转签名”作为实验规则，继续用盲测样本迭代。

“模型权重”是实验权重，不是统计学真实概率。
