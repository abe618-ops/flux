# 足球合参实验室 · 准确率与共振优化版 v1.1

基于现有 APK 的资产层优化，保留原有 15 种方法、随机起盘与复盘存储，主界面改为围绕 **主胜 / 客胜 / 大小2.5** 进行学习与排序。

## v1.1 主要变化

- **移除“单双”主过滤**：单双仍保留在旧数据结构中兼容历史记录，但不参与总体建议、方法排序和主复盘。
- **准确率排序**：15 种方法不再固定顺序；按“胜负历史分 58% + 大小历史分 42%”从高到低排列。
- **聊天样本弱先验**：当前对话中已经复盘的排序仅作为 8 场等效弱先验；本机真实开盒越多，先验影响越小。
- **2–5 家共振**：同向组合分别统计主胜、客胜、大球、小球；两家至少 4 次、三家至少 3 次、四/五家至少 2 次后才进入正式共振榜。
- **防止小样本假 100%**：共振排行优先看 Wilson 95% 区间下界，避免 2/2、3/3 自动冲到第一。
- **总体建议**：先按单法历史表现做加权票，再用合格共振做有限修正。共振只占 18%，不会机械用“多数家”覆盖历史表现。
- **冻结建议**：新建盲测时把“主/客 + 大小”及合参分写入封存上下文，赛后单独统计新版总体建议成绩。
- **复盘页**：新增单法排行榜、胜负共振榜、大小共振榜，以及新版总体建议的命中统计。

## 说明

这些统计是实验性复盘工具，不代表真实概率或确定性预测。当前样本仍小，排序会随着本机复盘逐步变化。

## APK 构建

工作流 `.github/workflows/football-fusion-resonance-build.yml` 会对重打包 APK 进行 zipalign 和 APK Signature Scheme 签名，并上传 `football-fusion-resonance-v1.1-apk` artifact。

此版本使用固定研究/调试签名，仅用于个人实验。若手机已经安装了同包名但不同签名的旧版本，可能需要先卸载旧版本再安装。
