# 闪记推送（FlashNotePush）· Android 系统分享版 v1.5.3

一个面向 Android 的轻量“提取 → 整理 → 分享”工具。它把 X/Twitter 长推文与 Articles、微信公众号文章以及普通网页内容提取到一个可编辑的正文预览中，再通过 Android 系统分享面板快速发送到邮箱、微信、笔记、网盘或其他应用。

## 主要功能

- **X 长推 / Articles 提取**：对公开 X/Twitter 帖子优先提取完整正文；Articles 会按标题、段落、列表、引用等结构合并，并尽量保留公开图片。
- **微信公众号全文提取**：识别 `mp.weixin.qq.com` 文章，提取正文区域、图注和可获取图片。
- **普通网页提取**：可从粘贴的网页链接、系统“分享给闪记推送”或选中文本进入应用并整理正文。
- **纯文字 / 图文 HTML 两种分享方式**：纯文字适合快速转发；图文 HTML 会生成完整 `.html` 附件，并保留可获取的结构与图片。
- **完整正文发送前可编辑**：提取结果先进入正文预览框，可修改、清理或补充后再发送。

## 便捷分享

闪记推送重点减少“复制—切换—粘贴—选收件人—再次确认”的重复操作：

1. **点击分享即可进入系统分享/邮件发送**：预设收件邮箱后，分享 Intent 会把邮箱地址放入 `EXTRA_EMAIL`；兼容的邮件应用可以直接带入收件人，其他分享目标会自动忽略该字段。
2. **分享后自动关闭闪记推送页面**：当前 v1.5.3 源码与 APK 的图文 HTML 分享在打开第三方发送应用后约 **8 秒**自动执行 `finishAndRemoveTask()`，关闭闪记推送自己的任务，不影响已经打开的邮件、微信或其他接收应用。纯文字分享保持原行为。
3. **剪贴板自动载入**：当正文输入框为空且应用处于前台时，会读取最近一条非敏感剪贴板内容并自动开始提取，不做后台持续监听。
4. **邮箱地址一次设置、后续复用**：默认收件邮箱只保存在本机偏好设置中，之后一键分享时自动带入，适合把网页、长文和资料快速发送到自己的固定邮箱。
5. **系统分享入口**：支持 Android `ACTION_SEND` 和 `PROCESS_TEXT`，可以从浏览器、X、微信或其他应用的分享菜单直接进入闪记推送。

> **关于“5 秒自动关闭”**：你提出的目标是 5 秒，但当前 v1.5.3 实际源码为 8 秒。为保证公开说明与程序实际行为一致，本版按 **8 秒**说明；后续可将 `MainActivity.java` 中的 `8000L` 改为 `5000L` 后发布新版。

### 关于 APK 签名

原始开发包中的私有 keystore、签名密码等敏感凭据**没有发布到 GitHub**。公共 APK 使用独立的 CI 构建签名，因此如果手机上已经安装了使用原开发私钥签名的同包名版本，Android 不允许直接覆盖安装；需要先卸载旧签名版本，或自行使用原开发密钥构建升级包。这样处理可以避免把应用签名私钥公开泄露。

## 隐私与权限

应用仅声明 `INTERNET` 权限；不申请通讯录、短信、存储、位置等权限。剪贴板只在应用可见且正文框为空时尝试读取；Android 12 及以上可能显示系统剪贴板访问提示。默认邮箱仅保存在本机。

公开 X 帖子通过 FxTwitter 兼容公开接口读取，仅传递公开帖子 ID；公众号和普通网页由应用直接请求原页面。受登录、付费墙、私密账号、删除内容、验证码或站点反抓取限制的页面无法保证提取。请只保存和分享你有权访问与使用的内容。
