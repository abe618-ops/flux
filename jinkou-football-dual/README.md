# 金口足球双盘 v1.0

Android离线原生应用。正时盘按当地时间自动取时支为地分、随机盘按安全随机种子独立抽取日期时辰与地分。两盘独立、65:35实验性合参。输出足球胜平负、半全场、总进球、比分、2.5大小球、单双；展开可见全部四位、神将干、课内外旺衰、用神、旬空和五动三动。支持自定时间、随机种子复演、锁定及赛果录入。

## 资料规则
《金口解秘》物理页17—24：月将加时、月令节气、贵人顺逆、五子元遁、取用、课内旺衰、五动三动。与《李鸿飞金口入门式》63/67页表格相冲突时采用《金口解秘》正文口径；亥加午时、地分卯应得申而不是寅。

## 重要界限
足球角色“将神→主队、贵神→客队”、模型泊松强度及65/35权重均是新增实验规则，不是古书固有方法，未经过外部独立盲测。日柱以2026-10-21戊辰日为校验点；太阳黄经与季节昼夜近似，节气临界需外部核验。没有实时比赛、赔率或实际赛果网络接口。不同应用ID，安装不会覆盖以前APP。

## 构建
JDK17 + Android SDK35 + Gradle8.10.2，在本目录运行：gradle :app:assembleDebug。GitHub Actions 自动出apk至 releases。
