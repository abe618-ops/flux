# Changelog

All notable changes to JShare / 极简分享 are documented here.

## [0.1.0] - 2026-09-18

### Added

- Native Android implementation in Kotlin
- Automatic LAN device discovery over UDP multicast/broadcast
- Direct TCP file transfer between Android devices
- File, photo, and video selection
- Android system Share-sheet integration
- Installed application picker
- Single APK export
- Split APK export as APKS
- APK/APKS installation using Android PackageInstaller
- SHA-256 transfer integrity verification
- Transfer progress display
- Drag-to-device sending interaction
- MediaStore Downloads integration
- GitHub Actions build workflow for Android API 36
- Public debug APK artifact

### Notes

This is the first public test release. Transport encryption, persistent trusted-device pairing, and resume/retry are not yet implemented.
