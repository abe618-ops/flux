# 足球合参实验室 v1.2 · 并存优化版

这一版是在 v1.1「准确率排序 + 2–5 家共振」基础上的并存实验版。

## 核心变化

- **前两项自动同向**：每次起盘先按当前历史综合表现确定排行榜前两项。如果两项的胜负方向不同，程序自动重新随机起盘；直到前两项胜负一致后才冻结本场。记录中保存 `topPairGate`（前两项、同向方向、自动抽取次数）。
- **仍以主胜 / 客胜 + 大小2.5 为主**：单双不进入主建议。
- **准确率高的排前面**：排序沿用 v1.1，综合分 = 58% 胜负历史分 + 42% 大小历史分；本机复盘逐渐覆盖聊天弱先验。
- **2–5 家共振继续保留**：达到最小样本门槛后才进入正式共振修正，避免小样本 100% 误导。
- **界面压缩**：随机合参页移除长标题和重复说明；绿色结果区压缩；15 家纵向排行直接放到结果下方，减少下翻距离；共振和封存细节默认折叠。

## 与 v1.1 同时安装

该并存版使用独立 applicationId：

`com.abe618.footballfusion.v12`

同时使用独立签名证书。因此它可以和 v1.1（`com.abe618.footballfusion.lab`）同时安装，数据空间也彼此独立。

> 仅仅换签名但保持同一个 applicationId 不能实现并存；Android 会把它视为同一个应用且因签名不一致拒绝覆盖。因此本版同时更换 applicationId 和签名。

## 自动同向规则

1. 根据已结算记录计算 15 家方法的历史综合排序。
2. 取排名第 1、2 的两个方法作为本场前两项。
3. 生成一套随机起盘。
4. 如果前两项胜负方向不同，自动重新抽取整套随机起盘。
5. 两项胜负一致后，才计算总体合参、2–5 家共振并冻结。
6. 为防设备异常死循环，单次最多自动抽取 240 次；正常情况下通常很快即可同向。

## 文件

- `assets/app.js`：自动重抽逻辑、紧凑 UI、前两项同向记录。
- `assets/engine.js`：v1.2 版本标记及 v1.1 准确率/共振内核。
- `assets/styles.css`：随机合参页紧凑布局。
- `assets/index.html`：缩短应用标题和导航文字。
- `tools/repack_coexist.py`：把既有 APK 的包名从 `com.abe618.footballfusion.lab` 等长改为 `com.abe618.footballfusion.v12`，并同步修复 DEX 校验值；随后需使用独立 keystore 签名。

这是实验性复盘工具，历史命中与共振不代表确定性预测。
