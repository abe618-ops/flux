# 卦金书排盘实验室 / Guajin Chart

Android 原生 Java 离线 APK，独立包名 com.abe618.guajin，可与旧版本占卜 / 足球 APK 并存。

## 项目现状（v0.1.0）

已实现：
- 第二册第 1—27 卦的三态三位数据库索引：圣、阳、阴，上中下三个位次；同一卦保存第二册 PDF 页码。
- 手动三态、系统时间按分钟确定性哈希、SecureRandom 随机排盘。
- 足球：独立泊松模型，输出胜平负概率、2.5 大小球、单双、小单/小双/大单/大双、3 个比分候选、半全场。
- 篮球：人工设定主客队期望得分、让分盘、总分盘，正态近似显示上/下盘及大/小分方向；单双近似 50%，不制造优势。
- 数字：3 位 / 5 位 SHA-256 固定种子取数，支持排列三/福彩3D的实验演示。
- 每次排盘保存时间、模型版本、卦序、页码、参数与预测；冻结后不允许直接编辑预测；录入结果并统计。
- 开赛时间早于排盘时点时不认定为事前预测；输入未来时间仅表示满足本地时间条件，非外部赛事核验。

## 原书依据与开发边界

用户上传的《卦金书》三册合计 128 个 PDF 页面。根据页码版研究笔记：
- 第一册（32 PDF页）包含请师、命卦、病情卦等，其中扫描细字和图像仍需校勘。
- 第二册（55 PDF页）形成 27 个“圣/阳/阴”三位组合；本项目只对这一部分的组合顺序和页码作确定性查表，不伪造具体卦辞。
- 第三册（41 PDF页）有多组编号卦例、五行及特殊图形；尚未编成可靠的数字规则，保留作为下一阶段资料。

注意：“正时盘按分钟取 SHA-256”、“三态微调 xG / 篮球期望得分”、“数字种子取数”全部是开发者新增的 **实验映射**，**不是原书原有起卦步骤或断辞**。不能证明有超越常规统计基线的预测优势。

三态软件索引定义（非原书数学编码）：
- 圣=0，阳=1，阴=2；
- 第 n 卦 = 1 + 9×第一态 + 3×第二态 + 第三态；
- 第一卦圣圣圣，第二卦圣圣阳，第二十七卦阴阴阴。
- 第二册 PDF 第 4—52 页对应卦序的页码由 GuajinEngine.PAGES 记录。

## 编译与安装

使用 JDK 17 + Gradle 8.9 + Android SDK 36。

在仓库根目录：
    cd guajin-app
    gradle :app:assembleDebug

生成：
    app/build/outputs/apk/debug/app-debug.apk

或者到 GitHub Actions 选择“Build Guajin Chart Android APK”，完成后下载 GuajinChart-v0.1.0-debug-APK artifact。它是 debug 签名测试版，非商店发布签名。

## 隐私和权限

无网络权限；所有排盘记录只保存在本机 SharedPreferences。无用户账号、无需后台服务、不会自动抓取体育彩票和球探的实时赔率与赛果。

## 目录

- app/src/main/java/com/abe618/guajin/GuajinEngine.java: 纯 Java 27 卦索引 + 实验模型
- app/src/main/java/com/abe618/guajin/MainActivity.java: 安卓界面、离线保存、复盘
- tests/EngineSmokeTest.java: 可由 javac 独立运行的基本测试
- .github/workflows/guajin-app-android.yml: Android 自动构建
