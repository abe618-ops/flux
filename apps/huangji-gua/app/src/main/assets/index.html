来源与公式

原书先天错综数：乾1、兑2、离3、震4、巽5、坎6、艮7、坤8。

原策数 C = 36 × 阳爻数 + 24 × 阴爻数。

设上卦编号 U，下卦编号 L，动爻 m：

  • m为1—3（内卦动）：S = C × (1 + 10L + m) + U + L + m
  • m为4—6（外卦动）：S = C × (1 + 10m + U) + U + L + m
  • 显示四位数为 S 除10000的余数，补足前导0。

元、会、运、世为四个数位，军旅分别关联元帅、副将、军马/士卒、兵甲（第33—34页与第62—64页）。

原书涉及起卦、五行、神煞、卦爻辞等多层解释。本原型仅实现计算可核的先天部分。后天阴爻轨数在整理本中112与120互异，暂未加入；游戏结果映射是后续研究，不属于原书明确算法。
