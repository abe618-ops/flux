# 兵法奇门·球赛随机盘（Android）

这是一个离线、无账号、无网络权限的民俗算法实验 App。

## 随机取局

本版采用 **1080 等概率状态**：

- 阴/阳遁：2
- 局数：1–9，共 9
- 六十时干支：60
- 合计：2 × 9 × 60 = **1080**

每次点击“完全随机取局”使用 `SecureRandom.nextInt(1080)` 均匀抽取一个编号，再解码为阴阳遁、局数和六十甲子时序。这样不是“先随机日期再排盘”，而是直接在完整的 1080 状态空间内等概率抽盘。

传统文献对“4320 / 1080 / 72 / 18 局”有不同层级的叙述：1080 可理解为风后所定的阴阳二遁固定局数，72、18 为进一步归约。项目用 1080 作为“随机硬局库”的工程化取法。

## 排盘要素

包含：

- 地盘三奇六仪
- 天盘干
- 九星
- 八门
- 八神
- 值符 / 值使
- 九宫格和八卦环形两种视图
- 主客宫标记

本版把“地盘时干宫＝主、天盘时干宫＝客”作为默认实验协议，并使用宫五行生克、门/星/神评分、景门和值使信息生成球赛输出。

## 直接输出

启动即随机起一局并显示：

- 胜平负：主胜 / 平 / 客胜
- 全场进球数
- 大小 2.5 参考
- 参考比分
- 主客强弱差

预测映射为本项目实验规则，并不是古籍中存在的现代足球公式，也没有经过统计学验证。

算法结构参考了公开的奇门排盘项目（包括 qfdk/qimen、deminzhang/qimen-go 等）对地盘、九星、八门、八神及值符值使的工程组织方式；本项目代码为独立实现。
