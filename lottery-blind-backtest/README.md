# 四彩·历史盲投回测

Android 历史开奖虚拟回测工具，覆盖：
- 中国福利彩票快乐8
- 中国福利彩票3D
- 中国体育彩票排列3
- 中国体育彩票排列5

流程为“选择真实历史期次 → 开奖号码保持隐藏 → 先锁定模拟投注 → 一键揭晓历史开奖结果 → 自动判奖 → 累计投入/返奖/净收益/ROI”。

## v1.0.0
- 支持按期号或日期查找、上一期/下一期、随机历史一期。
- 快乐8支持选一至选十的单式模拟，01-80 自动校验与机选。
- 福彩3D支持单选、组选3、组选6。
- 排列3支持直选、组选3、组选6。
- 排列5支持直选。
- 所有虚拟投注基础金额按2元/注计算，可设置倍数。
- 快乐8按历史规则分段结算：2025-12-30（第2025350期）起执行新版奖表，更早期次使用旧版奖表。
- 新版快乐8“选九中九”“选十中十”以及旧版“选十中十”属于浮动奖。若数据快照未含该期开奖公告的实际奖额，应用明确标记为“待官方公告核算”，不会使用封顶奖金冒充历史实际返奖。
- 自动统计模拟票数、累计投入、已核算返奖、净收益、ROI。

## 数据
构建时同步 17500 公共历史文本快照：
`3d_desc.txt`、`pl3_desc.txt`、`pl5_desc.txt`、`kl8_desc.txt`。
工作流对四份快照做存在性、文件大小和历史行数检查，数据异常时直接终止构建。

规则口径以中国福彩网/财政部门公布的快乐8、福彩3D规则，以及中国体育彩票官方排列3/排列5规则为准。

> 本项目仅用于历史开奖学习、模拟回测和统计，不接入真实彩票购买、支付或下单。
