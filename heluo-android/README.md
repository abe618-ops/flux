# 河洛数·随机赛事盘（Android v1）

这是一个实验性的 Android 河洛理数排盘与足球结果映射工具。

## v1 功能

- 一键随机起盘，不需要输入球队、时间、经纬度
- 随机生成四柱，并按河洛理数常见规则计算天地数
- 洛书配卦：1坎、2坤、3震、4巽、5中、6乾、7兑、8艮、9离
- 显示先天卦、后天卦、六神、简化六亲、元堂和年龄区间
- 结果优先：胜平负、总进球、大小2.5、双方进球、半全场、比分候选、单双
- 每盘保存随机种子，可复演同一盘
- 复制整盘结果

## 传统部分与实验部分

传统框架主要参考河洛理数中的干支取数、天地数、先天卦、元堂、后天卦和阳爻9年/阴爻6年的思路。

足球预测不是传统河洛理数的公认标准用途。本应用把上卦/下卦的五行生克、阴阳强弱、动爻等映射为赛事倾向，用于实验和后续回测。界面中的百分比是“倾向度”，不是统计概率。

## v1 简化项

- “遇五寄宫”使用固定化简化逻辑，尚未完整实现三元、男女命等古法分支。
- 元堂由随机种子确定，以满足“完全随机起盘”要求。
- 六亲暂按五行生克关系简化显示，尚未完整实现纳甲、世应。
- 尚未接入真实比赛数据库及历史回测。

## 后续建议

v2 可增加：
1. 完整元堂时辰表、纳甲、世应；
2. 元气、化工、至尊卦；
3. 流年、流月、流日、流时；
4. 输入实际比赛并保留随机起盘；
5. 历史赛事批量回测，分离“术数倾向度”和“统计模型概率”。

本项目仅作传统术数研究与娱乐实验，不构成投注建议。
