# 四术随机排盘 Android v0.1

第一版只做 **随机起数 + 原始排盘 + Seed复现**，暂不加入足球预测。

## 模块

1. **九爻易**
   - 随机生成天、人、地三个三爻经卦。
   - 组合空间 8×8×8 = 512。
   - 显示九爻线、卦名、三位二进制码。
   - “程序组合号”只是软件内部复现索引，不宣称为古籍原序。

2. **《灵棋经》**
   - 模拟12枚两面棋：上4、中4、下4。
   - 每枚独立掷出，保留0~4出现次数的真实二项分布，不把0~4做成等概率抽取。
   - 组合空间 5×5×5 = 125。

3. **七星数（试验盘）**
   - 红白两枚六面骰。
   - 21牌随机洗牌，分成上/中/下三组，每组7牌。
   - 目前只展示原始随机盘和七列结构；公开资料不足以核定完整古法牌名、符兆、断辞，因此不擅自补造。

4. **万事三角定律数字盘**
   - 从0~12随机生成天时、地时、人时三个数字。
   - 1~12按公开资料显示数字五行和阴阳分组。
   - 0在公开基础表中没有统一五行归属，本版保留为空位。

## 随机与复现

- “随机下一盘”使用 SecureRandom 生成64位Seed。
- 四套排盘由同一Seed派生，但各系统使用独立混合后的子Seed。
- 输入固定数字或文字Seed，可完整复现同一盘。
