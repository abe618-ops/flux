# 四术足球随机盲测 Android v0.2

在 v0.1 的“随机起数 + 原始排盘 + Seed复现”上增加足球实验映射层。

## 四套术数
- 九爻易：三才九爻、512组合。
- 灵棋经：十二棋，上中下各四枚，125组合。
- 七星数：双骰取符、21牌、三组七牌；公开资料缺口不补造古法断辞。
- 万事三角定律：0~12数字、阴阳五行、生克与169位。

## 每一术独立输出
- 胜平负排序
- 半全场
- 总进球数和区间
- 比分首选 / 次选
- 大小2.5
- 进球单双
- 结构强度
- 映射逻辑

## 四术合参
四术先独立判断再合并。灵棋经公开规则结构较完整，当前权重略高；七星数公开资料残缺，权重略低；九爻易和三角定律居中。该权重表示规则完整度，不是历史命中率。

## 盲测
- “下一场 · 随机起盘”：生成新 Seed。
- “固定 Seed 起盘”：数字或文字均可，可完整复现原盘与预测。
- 同一个 APK 包名 com.abe618.fourshushurandom，可覆盖升级 v0.1。
