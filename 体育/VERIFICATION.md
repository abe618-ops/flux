# v2.1 融合版验证要点

- 稳定基线：今天的 `竞彩虚拟投注 v1.3.2-startup-guard`，保留缓存、请求取消、保存单、赛果同步和本地即时结算。
- 盘口融合：采用旧版 `MarketMath` 的亚洲让球 / 大小球四分之一盘算法。
- 新增全球模式：全球比赛与欧赔分阶段载入；赛程先显示，赔率异步补充。
- 北单降级：主来源不可用时仍可显示备用公开赛程；替代欧赔始终标注来源，不冒充官方固定奖金。
- 本地结算：保存赔率 × 命中系数；同场多选作为不同组合分支，不在同场内互乘。
- 稳定保护：网络请求有连接、读取和页面总时限，切日期/页签会取消旧请求，退出页面关闭线程池。
- 本地语法与核心数学已做 smoke check；Android 完整 assemble 由 GitHub Actions 验证。
