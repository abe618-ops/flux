# FLUX 体育 · 指数学习

Android 本地虚拟足球赔率指数学习工具。**仅限赔率指数学习，正规投注请认准官方体育彩票。**

本项目不接入支付、充值、出票或真实购彩账户，金额均为本地模拟。

## v2.1 融合版

- **竞彩足球**：保留胜平负、让球胜平负、比分、总进球、半全场等市场，可在同一保存单中组合。
- **北京单场**：比赛列表先快速载入，再异步补赔率；参考欧赔依次尝试 12BET、Bet365、澳门，来源失败时不编造默认赔率。
- **全球指数**：按日期读取公开足球赛程，先显示比赛，再后台补欧赔；大小球（OU）和亚洲让球（AH）有独立盘口入口。
- **比赛结束即可本地结算**：公开完场比分出现后，按保存时的十进制赔率和盘口规则直接计算，不等待体彩官方派奖。
- **收益展示**：保存单显示投入、回报、净收益、收益率，以及每场投注项、锁定赔率、赛果和命中状态。
- **自行计算**：支持手工录入/修正全场、半场比分，并立即重新结算。
- **四分之一盘口**：0.25 / 0.75 等盘口拆分为相邻半球计算，支持赢半、输半、走盘。
- **默认模拟金额**：500 元，可在保存时修改。
- **稳定性**：缓存优先、短连接/读取超时、旧请求主动取消、16 秒总停止保护、Activity 销毁时关闭线程池；不再注册旧版后台 JobService。

## 数据原则

第三方公开页面可能改变结构或访问策略。程序遇到失败时保留缓存并快速停止，不绕过登录、验证码、付费墙或访问限制；没有可靠赔率就显示缺失，不使用内置默认数字冒充实时行情。

北京单场主来源不可用时，可使用能够取得的公开赛程和赛前欧赔作为**指数学习替代参考**，界面同时保留具体来源文字，避免把替代数据误认为官方北单固定奖金。
