# 大衍足球·盲测（Android）

独立包名：`com.abe618.dayanfootball`，可与仓库中既有足球/术数 APK 并存。

## 核心
- 真实模拟传统大衍筮法：50策虚一，用49策；分二、挂一、揲四、归奇；三变成一爻，十八变成六爻。
- 记录每一爻三次余策与 6/7/8/9；6、9为动爻。
- 自动识别本卦、变卦、八宫世应、纳甲地支五行。
- 标准映射：上卦+世=主，下卦+应=客。
- 镜像诊断：同步计算完全反向的主客输出，用于解决盲测中出现的“比分结构接近但方向镜像”问题。
- 输出：胜平负、半全场、总进球、2.5大小、单双、双方进球、比分池、净胜球。

## 盲测闭环
1. 输入可选比赛名。
2. 随机种子留空则自动生成；填入数字可复现同一盘。
3. 点击“大衍起盘并冻结”，预测自动写入本机历史。
4. 比赛结束后录入真实比分。
5. 自动统计正式方向、标准映射、镜像映射、大小、单双、比分池命中率。
6. “自动校准”只有在已复盘样本 >= 10 且镜像方向领先标准 >= 15 个百分点时，才切换为镜像映射，防止少量样本过拟合。

## 重要修正
聊天盲测已经证明“0动=小球”并不成立，因此本版不再采用该简单规则。进球强度同时考虑：
- 动爻数与位置
- 本卦/变卦五行生克
- 世应纳甲五行
- 本变方向反转
- 老阳密度
- 生克冲突强度

## 构建
GitHub Actions 工作流：`.github/workflows/dayan-football-android.yml`

产物：
`dist/DayanFootball-v1.0-debug.apk`

Debug APK 由 Android 构建工具自动签名，工作流会使用 apksigner 二次验证。

> 本项目是传统筮法的实验性盲测工具，没有科学证据证明其能够预测足球赛果，不构成投注建议。
