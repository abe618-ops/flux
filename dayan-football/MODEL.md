# 大衍足球 V1.0 模型冻结说明

## 1. 起盘
49策开始，每爻执行三变：
1. 随机分二；
2. 右堆挂一；
3. 左右分别揲四；
4. 归奇；
5. 三变余策除以4得到 6/7/8/9。
六爻共十八变。

## 2. 主客
标准模型固定：
- 主方：上卦 + 世爻
- 客方：下卦 + 应爻

同时保留镜像模型：
- 将标准胜负评分整体反向，但不篡改原始卦盘。

## 3. 胜负评分
综合：
- 本卦上下卦生克
- 变卦上下卦生克
- 世应纳甲地支五行生克
- 本变趋势差
- 世/应是否为动爻

正分偏主、负分偏客，绝对值较低进入平局区。

## 4. 半全场
- 初、二、三爻：前程/上半场权重
- 四、五、上爻：后程/下半场权重
- 若本卦方向与变卦方向明显反转，允许主/客或客/主型翻转输出。

## 5. 进球
不再使用“动爻多少直接映射进球”的单指标规则。
进球均值由动爻、生克冲突、本变反转、老阳等共同决定，再生成主进球数、次选与范围。

## 6. 校准
每场必须先冻结，再录入赛果。
标准/镜像命中分别统计；自动模式需要至少10场样本且镜像领先15个百分点才改变方向映射。
