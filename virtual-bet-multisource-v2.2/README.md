# le xu 盘口训练 · 独立版 3.1.0

本版本在原多源虚拟盘口训练内核上补齐“玩法展示 + 开奖计算 + 智能串关默认”。

- 独立 applicationId：`com.flux.lexu.training.v31`，可与现有 3.0.1 并存，避免签名冲突导致安装失败。
- 新增/补齐玩法入口：比分、总进球、半全场、上下单双、进球单双、双方进球，以及原有胜平负、让球胜平负、大小球、亚洲让球。
- 比分按全场精确比分结算；半全场按半场结果 + 全场结果结算；单双、双方进球等可直接由全场比分自动判定。
- 赛果可自动同步，也可手工录入/修正全场比分和半场比分后立即重算。
- 选择 1 场时默认“单关”；选择 2 场时默认“2串1”；3 场及以上按场次数自动选对应“n串1”，仍可手动切换其它串法。
- 保存单显示投入、回报、净收益、收益率，以及每个投注项的“命中 / 未中 / 待完场 / 待补数据”。
- 北单/全球指数仍支持 12BET → 10BET → Bet365 → Crown → 澳门的浮动欧赔优先级；缺少某玩法公开赔率时支持“手工参考录入”。
- 仅用于本地赔率指数学习与虚拟模拟，不接入支付、充值、出票或真实投注账户。

构建产物：`dist/le-xu-pan-training-v3.1.0.apk`。
