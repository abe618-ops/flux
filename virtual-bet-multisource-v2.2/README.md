# 竞彩北单模拟 · 多源版 v2.2

从 FLUX 体育 v2.1 稳定内核分出的可并存版本。

- 独立 applicationId：`com.flux.virtualbet.multisource`，不会覆盖旧版。
- 北单赔率：自动优先 12BET → 10BET → Bet365 → Crown → 澳门，也可固定单一来源。
- 不采用官方固定奖金作为北单主要赔率；保存时锁定浮动赔率，完场后按公开比分本地结算。
- 全球投注保留单关、OU、AH；支持单关与串关。
- 每页 12 场并预取下一页赔率，界面压缩行距与卡片间距。
- 构建过程校验 APK 包名、签名和 zipalign。

仅用于本地赔率指数学习与虚拟模拟，不接入支付、充值、出票或真实投注账户。
