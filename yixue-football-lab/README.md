# 易学足球合参 · YiXue Football Lab

Android 离线实验工具：统计模型 + 多术数随机盲测 + 赛后复盘。

## v1.2 随机修复

修复“点击下一场后，各术数盘面/结果变化不明显”的问题。

### 根因
旧版主种子主要由 `主队|客队|开赛时间` 计算。连续测试时若队名与分钟级开赛时间相同，会重复得到相同 seed；部分术数又共用同一 seed，因此盘面高度重复。

### v1.2 规则
1. 每次点击“下一场”强制生成新的 32-bit `matchNonce`。
2. 自动刷新新的 3 位、4 位、9 位基础随机数。
3. 每门术数使用独立派生 seed：`deriveSeed(matchSeed, moduleId, input)`。
4. 小六壬抽牌、响马卦牌号、小金口四位、归藏九位、鬼谷 mod8/mod9、神易数三位、诸葛签号等均分别刷新。
5. 界面显示每门术数独立 6 位随机码，便于盲测冻结和赛后复盘。
6. 手动输入 3/4/9 位数字仍保留，但会叠加本场随机层，避免不同术数机械共用同一个结果。
7. 复盘统计及 1X2/大小球自适应权重保持不变。

## 验证
使用相同主客队、相同开赛时间连续执行两次“下一场”：
- 本场 nonce：变化
- 3/4/9 位基础随机数：变化
- 12 个术数模块随机码：全部变化

> 术数模块仅作为实验性随机特征与盲测对象，不代表已被科学验证能够预测足球比赛。
