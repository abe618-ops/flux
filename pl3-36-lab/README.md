# 排列三 36 术数实验室 V0.1
独立 WebView Android App，完全离线。保留百十个位三轮、36种随机术数接口、历史风洞10期、SHA256封盘、开盒和3/4家组合复盘。
运行 `gradle assembleDebug` 生成自签名调试APK。最低Android7.0（API24）。
历史开奖第三方未逐期官方核验，属于回溯遮盲研究而非真正赛前预测。术数映射为实验适配，不宣称能预测随机开奖号码。


## V0.2
新增无需期号的任意历史期次随机共振入口。参考快照组合需在百/十/个位的大小、单双全部得到三家或四家同向才封盘。随机挑历史期号后只重抽随机种子，不读取开奖结果；回溯榜单非真实样本外准确率。新包名 cn.abe618.pl3lab.resonance，不覆盖v0.1。
