# V2 预测模型说明

## 主客定位

- 主队：地盘时干落宫；甲时取值符原宫。
- 客队：天盘时干落宫；甲时取值符落宫。
- 保留原 APK 的值符随时干、值使门、天盘星、八门、八神排布规则。

## 去偏原则

原版 `homeGong == zhiFuGong`，而值符神与值符宫又分别参与主队评分，导致结构性主队优势。V2 在比较分中将值符神中性化，不再叠加“值符宫 +0.35”。

## 合参维度

`finalIndex = 0.58*primary + 0.12*technique + 0.09*medal + 0.08*process + tieFactor*0.13*secondary`

- `primary`：主客宫门、星、神、宫内五行 + 主客五行直接生克。
- `technique`：景门宫五行对主客的作用差。
- `medal`：地盘辛与天盘辛对主客的作用差。
- `process`：值使落宫五行对主客的作用差。
- `secondary`：值符原宫与值使宫的次判。
- `tieFactor`：天地盘时干同宫时提高次判权重，减少机械平局。

五个维度同时做方向投票，最终指数接近阈值时用一致性投票二次判定。
