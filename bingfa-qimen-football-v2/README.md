# 兵法奇门·球赛随机盘 V2

这是对原 APK `兵法奇门·球赛随机盘` 的排盘逻辑复现与预测层去偏重构版。原盘的 1080 随机局、阴阳遁、局数、旬仪、地盘/天盘、九星、八门、八神生成逻辑保留；预测层不再把“值符随时干落主宫”直接当成主队加分。

## 原版问题定位

将原 APK 的判定逻辑完整复现后，对 1080 个随机局全部枚举：

| 输出 | 原版 | 比例 |
|---|---:|---:|
| 主胜 | 367 | 34.0% |
| 平 | 615 | 56.9% |
| 客胜 | 98 | 9.1% |

根因是原盘先令 `zhiFuGong = homeGong`，预测时又给值符神与值符宫重复加分；同时 ±1.05 的平局阈值过宽，形成“主胜/平局”结构性偏置。

## V2 修复

预测改为多维合参：

1. 主客宫八门、九星、八神与宫内生克；
2. 主客宫五行直接关系；
3. 景门（技术/战术）辅助；
4. 地盘辛 + 天盘辛辅助；
5. 值使宫（比赛过程）辅助；
6. 值符原宫 vs 值使宫次判，专门减少天地盘时干同宫时的机械平局。

值符仍完整显示在盘面中，但在主客比较层不再给予主队固定加成。V2 对完整 1080 状态空间枚举得到：主胜 377（34.9%）、平 326（30.2%）、客胜 377（34.9%）。这只说明消除了结构性输出偏差，不代表真实比赛命中率。

界面会直接显示五个主要维度的分值，方便后续根据真实赛果做盲测复盘、调整权重。

## 构建

```bash
gradle :app:assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`。

包名为 `com.abe618.bingfaqimenv2`，可与旧版并存安装。

> 民俗算法实验，不代表真实比赛概率，不作投注依据。
