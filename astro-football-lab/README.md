# 三术足球合参 · Android

一个用于足球盲测研究的本地 Android 应用，把三种随机体系与数学概率层拆开：

- 地占术：四母、四女、四甥、左右见证、Judge，输出主/平/客、进球能量、BTTS、波动。
- 西洋占星：随机抽取 1900—2099 UTC 时间点，使用轻量平均黄经、上升、传统宫主和月亮关系构造实验盘。
- 印度占星 / KP：随机时间、Lahiri 近似岁差、1/7宫、6/11竞技轴、月宿和 KP 1—249。
- 数学合参：M1 初盘、M2 自动归一、K 指数衰减、三术相关性折扣、方向熵、负二项进球尾部、镜像比分。
- 赛后复盘：录入真实比分后，本地统计胜平负、大小2.5、单双、BTTS、首选比分、候选比分覆盖率。

## 使用方式

1. 可输入真实队名，也可用 A / B 做匿名盲测。
2. 随机种子留空则自动生成；保存种子即可完整复现同一盘。
3. 点击“开始三术合参”一次完成 M1、M2 自动归一和数学概率层。
4. 比赛结束后录入比分，程序自动保存复盘指标。
5. “复盘统计”只统计赛前已冻结的预测，不用赛后规则回填历史。

## 当前内核

- M2 权重随 `K` 指数衰减，深层归一不直接覆盖初盘。
- 三术同向使用相关性折扣，不当作三个完全独立证据。
- 主客概率接近且最高概率不足时，平局权重自动上升。
- 总进球使用均值 `μ` + 波动度，并以负二项分布保留高比分尾部。
- 大小、单双、BTTS 从比分概率池分别计算。
- 方向不稳时自动提供镜像比分。
- 支持候选比分与赛后精确命中统计。

## 构建

项目为原生 Java + Android SDK，无第三方运行时依赖：

```bash
gradle :app:assembleDebug
```

输出：`app/build/outputs/apk/debug/app-debug.apk`

GitHub Actions 会自动构建并上传 `TriAstroFootball-v1.0-debug.apk`。

## 重要边界

占星与地占没有可靠科学证据证明能够预测足球比赛。本项目把它们作为可复现的随机特征生成器，用于盲测、统计和模型实验，不构成投注建议。

西洋与印度模块当前采用轻量天文近似算法，不等同于 Swiss Ephemeris 等专业星历。后续可以替换为高精度星历，而保持合参、概率与复盘层不变。
