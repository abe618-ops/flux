# 破界 PoJie v0.1

一个专门解决“知道该做，但迟迟不开始”的 Android 执行力训练器。

## 核心闭环

**找到堵点 → 缩小下一步 → 5 分钟启动 → 承受一点不适 → 完成/推进 → 即时反馈 → 晚间复盘**

它不是普通 Todo。首页只强调少数真正重要的动作：

- **今天最难的一件事**：每天选择一个最想逃避但值得推进的事项。
- **破界难度 1–5 星**：默认建议 2–3 星，强调可持续的微不适。
- **5 分钟点火**：把“完成任务”降级为“先启动 5 分钟”。
- **堵点诊断**：不知道怎么开始、事情太大、怕失败、不想面对、太麻烦、容易忘、没时间、不重要。
- **固定底线**：少数每天需要打勾的基本动作。
- **今日新尝试**：每天接触一点新方法、新问题或新经验。
- **语音输入**：挑战、新尝试、复盘均可直接调用 Android 系统语音识别。
- **即时执行值**：破界 +20、底线任务 +5、新尝试 +10、复盘 +5、完成 5 分钟启动 +2。
- **复盘与统计**：累计启动次数、破界次数、任务完成次数、新尝试次数和常见堵点。
- **本地优先**：SharedPreferences 本地存储，不需要账号或服务器。
- **导出**：可把当日记录以纯文本分享到任意应用。

## 第一性原理

行动失败往往不是“缺少计划”，而是开始那一瞬间的阻力过高。因此 v0.1 主要优化从 0 到 1：

> 行动倾向 ≈ 清晰下一步 × 立即开始 × 即时反馈 ÷（启动阻力 × 不确定性 × 不适感）

这只是产品设计模型，不是心理学公式。

## 构建

项目使用原生 Java + Android SDK，无第三方运行时依赖：

```bash
gradle :app:assembleDebug
```

APK：`app/build/outputs/apk/debug/app-debug.apk`

GitHub Actions 工作流 `pojie-android.yml` 会自动构建并上传 APK artifact；当前 Runner 直接使用预装 Android SDK，以避免旧 `tools` 包造成的环境初始化失败。

## 当前版本边界

v0.1 先验证核心执行闭环。后续可加入：每日提醒/闹钟、桌面小组件、语音自然语言拆任务、Markdown/CSV 历史导出、连续恢复力、奖励商店、主动识别长期堵点。
