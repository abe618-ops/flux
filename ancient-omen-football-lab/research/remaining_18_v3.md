## 命令行运行

```bash
# 需要本地JDK17及可访问 Maven Central 的网络
bash ancient-omen-football-lab/tools/run-traditional.sh 2026-10-17T13:00
# 原始Qimen旧代码以及Maya/Ifa/Sikidy/Raml/兵占实验
bash ancient-omen-football-lab/tools/run-legacy.sh serial:1080

# Web版的18个注册入口在index.html最末阶段面板
node ancient-omen-football-lab/tests/test_v3.cjs
```

注意：所有时间须为**目标地区本地时刻**并另行保存时区和历法约定。真实彩票与比赛事件严禁由程序假设具体赛前数据。Java历算依赖原项目指定的 `cn.6tail:lunar:1.7.7`，运行脚本从Maven Central获取。
