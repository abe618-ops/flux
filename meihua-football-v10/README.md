# 梅花足球合参 V1.0

这是根据本轮连续盲测/复盘重写的 Android 实验版。与 V0.9 最大区别不是界面，而是**判断顺序完全重构**，尽量与聊天中的人工合参逻辑保持一致。

## V1.0 核心顺序

1. **强激活 A**：同位策数/轨数绝对差 >= 3。
2. **克制 K 压缩总球**：
   - K=3：A-1；
   - K>=4：A-(K-1)；
   - K=0、A>=4 且强点高度集中一侧：+1。
3. **强点不仅计数量，还计强度**：例如差7比差3权重大。
4. **A=2 且强点一边一个**：1:1 权重大幅提高。
5. **K>=3 且总球压到2、强点只轻微偏斜**：提高平局/1:1权重。
6. **核心三区（元+会+运）**：若差值>=8，且领先侧核心至少两个值>=8，可覆盖单纯生克方向。
7. **零值、生克、总量、核心差**：作为比分集中、零封和方向修正，不再单独一票定输赢。
8. **经验层**：内置本轮已完成复盘的8个样本，用相似度参与经验权重；若精确录入已复盘样本，则直接回放其已知结果，用于回归核验。

## 起盘/录入

- 支持随机起盘、活时起盘；
- 支持手工复刻截图；
- 五个位置：万、元、会、运、世；
- 每侧输入数字0–9，并选择演卦；五行由八卦自动映射。
